자주 묻는 질문

카테고리코드는 어디서 찾나요?

QSM → 상품관리 → 상품 대량등록/수정에서 카테고리 엑셀을 내려받아 소분류 코드(9자리)를 사용하세요.

배송비코드를 비워두면?

기본 배송비코드 605022 (TracX Logis, 무료배송)가 자동으로 들어갑니다.

API 키가 만료되면?

2027-10-13에 만료됩니다. API 키 관리 페이지에서 ‘재발급’을 누른 뒤 시트 메뉴 → ② API 키 등록/변경에 붙여넣으세요.

오류가 나면 어떻게 확인하나요?

각 탭의 결과 열과 로그 탭에 오류 코드와 메시지가 남습니다. -90004/-90005는 키 만료, -10001은 입력값 오류입니다.

API 사용 조건: 서비스 포인트 0점 이상, 발송지연·미답변 문의·미처리 클레임이 없어야 합니다.
